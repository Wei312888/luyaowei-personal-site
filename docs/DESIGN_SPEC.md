# 视觉规范 ·「蓝图档案 BLUEPRINT ARCHIVE」(2026-09 重塑版)

> 本文档取代旧版 paper-minimal 规范。旧版为**反例参考**:其「暖白纸底 + 1px 细线 + 克莱因蓝点缀」的语言保留为底色基底,但本版引入全新的蓝色印稿体系、毫米刻度、网格图纸与档案编号识别物——全站从「一份简历」升级为「一间蓝图档案室」。
> 本规范为站主确认的唯一视觉权威,前端 CSS 不得偏离;动效规则见 §5 允许/禁用清单。

## 1. 设计关键词与个性定位

- **一句话**:「一间可翻阅的蓝图档案室」——一个嵌入式 × AI 工程师的自建站,像一本工程蓝图文档:蓝印为魂、纸底为躯、刻度为饰、波形为脉。
- 个性识别物(全站出现,构成可辨识度):
  1. **毫米刻度尺**:页眉下沿一条 4px 高刻度条(等宽数字标注 0…12),全站唯一横贯装饰。
  2. **SVG 网格图纸**:hero 版头与详情页版头使用 1px 细网格(pattern),模拟工程图纸底纹。
  3. **波形单线**:一条从姓名下延伸的克莱因蓝波形(单 stroke,5 个点阵),作为签名式装饰。
  4. **档案编号**:一级页 01–07、详情章节 01–06 一律等宽编号;AI 面板编号 `QUICK ASK·01`。
  5. **「陆」字印章**:favicon 沿用蓝底白"陆";页脚图章以蓝色描边方框呈现。

- **底部翻页导航**(每页必有):`← 上一页` + 编号列表(01 首页 · 02 全览 · 03 项目 · 04 进程 · 05 校园 · 06 获奖 · 07 实习,当前项克莱因蓝)+ `下一页 →`;点击直达,全站统一翻页过渡。

### 3.2 焦点等级(F0/F1/F2)
- **F0**:每页唯一主角,最大字重字号(姓名类 52–84px / 页标题 34–44px / 焦点卡 24–28px),克莱因蓝可出现在编号与波形。
- **F1**:次级标题(22–26px 衬线),墨黑,下接 1px 细线。
- **F2**:正文/条目(14–16px),暖灰分隔。
- 每页仅 1 个 F0;禁止多主角;禁止"每页超大标题"堆砌。

## 4. 组件规则

- **AI 面板**(首页 hero):直角、1px 墨黑边框、内部纯白 `--paper`;顶部等宽小标签 `QUICK ASK · 依据站点公开内容回答`;欢迎语第一人称;输入框 1px 细线、高 64px、focus 克莱因蓝(无阴影)+ 右侧描边「发送」按钮(与输入框同高);5 个描边快捷问题(seed `quickQuestions` 下发,可增补);消息区就地展开(max-height 440px 内部滚动);AI 回答按轻量 Markdown 渲染(段落/列表/粗体/行内代码,零依赖、先转义后拼标签);回答流式期间输入框显示克莱因蓝打字光标;底部小字 `由陆耀威自建的个人AI向您回答`。
- **项目卡片**:非均质栅格——旗舰大卡(跨 2 列,含架构图缩略)+ 其余错落小卡;卡片直角 1px 细线、内底 `--paper`;标题(→详情页)下方完整 URL 行(mono 小号、可折行、可点击);「点击查看详情页 →」描边入口;hover 仅边框→克莱因蓝(旗舰卡允许 ≤2px 上移)。
- **骨架印戳**(详情页内容待补):`详细内容整理中` 用 1px 描边小方框 + mono 文字,蓝色;不编造成果。
- **章节树**(详情页):左侧节点(可点击)+ SVG 连线;移动端降级纵向折叠卡。
- **图框**:1px 细线直角 + 网格底纹 wrap;图片 display:block。
- **浮动问答入口**:右下角「问问我」,仅一级页(首页除外)显示。

## 5. 动效规则:允许清单 / 禁用清单(可直接审核)

> **v2 修订(design-v2 §1.2/§1.5)**:允许清单由「6 类」升级为「9 类」——页切换 5 变体、4 级 lift、新增切页水滴音、新增 7 页信号线 hover 变形、新增鼠标轨迹拖尾;禁用项仅细化措辞,不新增禁用形态。

### 允许(共 9 类;全部 ≤600ms;入口动效每页仅 1 次;每屏活跃动效 ≤2 处)
1. **页切换过渡(5 变体)**:浮动 float(默认)/ 切图 sheet / 虚化 fade / 拉近 zoom / 模糊 soft,由站点配置单值 `html[data-fx]`(localStorage / 静态 `<html data-fx>` / `window.setPageFx`)切换。新页进入恒 420ms `--ease-standard`;旧页离场 240–280ms(fade 变体 0.3s,有意选择,整体仍 ≤600ms);模糊变体仅 View Transitions 快照层启用,class 回退自动降级为浮动;优先 View Transitions API,不支持则 class 回退。
2. **切页水滴音**(站主 P2):Web Audio 现场合成(正弦 900→210Hz ≤200ms),零外部资源;首次 pointerdown/keydown 解锁即播,`prefers-reduced-motion` / 无交互不响。
3. **滚动渐入**:IntersectionObserver,420ms,stagger ≤60ms,仅首屏以下条目,仅触发一次。
4. **hover 反馈(4 级 lift)**:颜色/边框 墨黑→克莱因蓝 150ms;位移 + 单层冷墨灰投影(`--lift-s/m/l`,blur ≤18px)进入 180ms / 离开 150ms。分级:L1 文本 -1px(无投影)/ L2 控件 -2px(`--lift-s`)/ L3 卡面 -4px(`--lift-m`)/ L4 焦点面板 -3px(`--lift-l`);仅桌面 `(hover:hover)+(pointer:fine)`,触屏/减弱动效无位移无投影。
5. **细节进场**:章节树节点依次点亮 + SVG 连线 dash 绘制,600ms,进入页面时一次。
6. **7 页专属信号线 hover 变形**:首页折线→正弦、项目页谐波合成(正弦→+3→+5→+7→方波)、其余页描线重绘;≤600ms、帧停留 ≥80ms、单处不循环,仅 `pointer:fine`;`reduced-motion` / 触屏下静态显示。
7. **光标跟随/视差**:仅①**首页 hero**(十字准星光标 + 网格/波形层 2–4px 视差,rAF 节流)②**详情页架构图**(轻微视差);`pointer: coarse` 或 `prefers-reduced-motion` 下整体禁用。(轨迹拖尾属指针装饰,非视差跟随)
8. **鼠标轨迹拖尾**(新增):1.5px 克莱因蓝单线墨迹、单点寿命 450ms、峰值 α0.30(站主「加浓」决策)、≤48 点、canvas 单例、rAF 自停;`pointer:coarse` / `prefers-reduced-motion` 下不创建。
9. **AI 面板打字光标闪**(纯 CSS,1.2s loop;仅面板输入态);AI 面板 5 点信号波点 focus 单次点亮 420ms(60ms stagger),不循环。

### 禁用(任何实现不得出现)
弹跳/回弹、旋转式入场、自动轮播/跑马灯、粒子风暴(拖尾为单线墨迹,无物理/无随机/无爆炸,不构成粒子风暴)、全局渐变背景、玻璃拟态(页切换 blur 为过渡瞬时模糊,仅 VT 快照层,非持久玻璃拟态)、每页超大标题堆砌、滚动劫持、点击波纹、全站光标跟随、阴影悬浮堆叠(细化为:**多层(≥2 层)阴影堆叠、彩色投影、大模糊(>20px)投影**;单层冷墨灰投影在允许 4 内)、emoji 装饰、弹窗闪烁提示。
**模板化禁用项**:均质同尺寸卡片栅格、紫蓝渐变+圆角大卡+大投影、空泛口号式居中大标语(如"开启未来")、AI 套话文案(如"一站式智能解决方案")。

## 6. 文案基调

- 第一人称、具体、克制,像本人手写;不喊口号;待补充就写「待补充」。
- AI 面板与访谈提示统一为「由陆耀威自建的个人AI向您回答」。

## 7. 无障碍与降级

- `prefers-reduced-motion: reduce`:关闭本节全部动效(过渡/渐入/连线/视差/光标跟随/lift 位移与阴影/切页变体/拖尾/信号线 morph/水滴音),仅保留颜色变化与下划线;拖尾 Canvas 不创建。
- 移动端(<720px):章节树→纵向折叠卡;底部翻页导航始终可达;无光标跟随;网格底纹降为浅色(不密集);不出现 lift 位移、不创建拖尾 Canvas、信号线图案仅静态降浅装饰、hover 预览夹不显示。
- 内容加载失败:显示一行克制错误,不破坏页面框架。
