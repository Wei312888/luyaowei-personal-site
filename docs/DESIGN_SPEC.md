# 视觉规范（已经站主确认，两页共用，不得偏离）

## 设计关键词
纯色、简约、高端、大气、上档次；少量色彩点缀。编辑部/人物特稿式的极简排版，像一份为自己手写的个人档案，绝不能像模板站。

首页以「AI 问答对话」为第一屏主角（AI-first hero）：它不是营销鸡汤式的居中大标语，而是纸面极简、常展开的大号 AI 对话面板，让访客「先问起来，再看档案」。

## 设计令牌（CSS 变量原样使用）

```css
--bg: #FAFAF7;        /* 暖白纸底，全站唯一底色 */
--ink: #1A1A1A;       /* 墨黑正文 */
--ink-2: #6F6C64;     /* 次级文字（暖灰） */
--hairline: #E7E4DB;  /* 1px 细分隔线 */
--accent: #002FA7;    /* 克莱因蓝，唯一强调色 */
```

- 禁止：渐变、玻璃拟态、投影堆砌、圆角卡片阵列、emoji、营销话术、居中花哨大标语 hero、三栏图标卡片、入场动效堆砌、居中排版的营销型首屏。
- 允许的装饰：1px 细线、等宽编号（01/02…）、大留白、字重与字号对比、一处克莱因蓝点缀（当前导航态、链接 hover、编号）。
- 关于「hero」的说明：首页可以且应当有大号 AI 对话面板作为第一屏主角（AI-first hero），但它必须延续纸面极简——直角、1px 墨黑边框、无圆角无阴影、无渐变、无花哨动效，而非模板化的居中营销 hero。

## 字体（零外链，不用任何 webfont/CDN，直接系统字体栈）

```css
--font-serif: "Noto Serif SC","Source Han Serif SC","Songti SC","SimSun",serif; /* 特大标题 */
--font-sans: -apple-system,"PingFang SC","Microsoft YaHei","Segoe UI",sans-serif; /* 正文 */
--font-mono: ui-monospace,"SF Mono",Consolas,"Cascadia Mono",monospace;           /* 编号/参数/元信息 */
```

## 排版

- 内容最大宽约 1060px，正文窄栏（约 34em）。
- 顶部固定编号目录：`01 个人 · 02 项目 · 03 进程 · 04 校园 · 05 荣誉 · 06 实习`，锚点滚动；当前节编号变克莱因蓝。
- 节标题格式：等宽小号 `01 / PROFILE` + 衬线大字「个人介绍」，上下 1px 细线。
- 密度低、留白大；数据（指标、时间、版本号）用等宽字体小标签呈现。

## 访客端结构（/）

1. 顶部窄栏：左「陆耀威 LU YAOWEI」，右编号目录 + 「问问我」按钮（打开右下角对话浮层）。
2. 第一屏（AI-first hero，非营销 hero）：身份行 = 衬线大字姓名 + 一句话卖点（求职意向）+ 元信息行（邮箱 / 广西梧州 / 共青团员，等宽字体）+ **大号常展开 AI 对话面板**（见下节）。AI 面板为第一屏主角，一屏内即见。
3. 展示区（AI 面板下方）：第一人称简介段 + 六个编号节，内容全部来自 `GET /api/content` 动态渲染，HTML 里不得硬编码简历内容。
4. 「04 校园经历」内容为空时显示一行克制的说明（如：这一栏还没写好，校园经历整理后补上。），不得报错、不得留空白节；内容补齐后正常排版展示。
5. 页脚：邮箱、一行第一人称说明（如「本站由我自己搭建，内容在管理端维护」）。
6. 对话框（右下角浮层）：纸面同风格面板；SSE 流式逐字渲染；第一人称回答；不浪费动效；与首屏 AI 面板共用同一套消息渲染 / SSE 流式实现。
7. 首屏 AI 面板与对话框浮层的底部提示统一为「由陆耀威自建的个人AI向您回答」。

## 首屏 AI 对话面板（AI-first hero，大号常展开）

- 位置：身份行之后、六个编号节之前，作为第一屏主角，一屏内即见；内容宽约 1060px 内的整块布局。
- 面板形态：大号、默认常展开（无需点击展开）；直角、1px 墨黑边框（--ink），无圆角、无阴影、无渐变；内部按纸面留白排版。
- 提示行：面板顶部一行等宽小字（如「QUICK ASK · 依据站点公开内容回答」）。
- 欢迎语：一句第一人称克制的介绍（如「你好，我是陆耀威的站点分身。下面的公开内容——项目、技能、实习、校园经历——都可以问我。」）。
- 主输入框：直角白底、1px 细线（--hairline），高约 64px，placeholder「有问题可以问陆耀威，直接输入…」；focus 时边框变克莱因蓝（禁止阴影/渐变）。
- 快捷问题：输入框下方一排 3 个描边快捷问题按钮（如「EDA Agent 桥是怎么工作的？」「wei+ 串口助手能做什么？」「你会哪些技能？」）。
- 对话流：发送后输入框下方就地展开（消息区过长时内部滚动，max-height 约 440px）；与右下角浮层共用同一套消息渲染与 SSE 流式状态；发送后清空并保持 focus。
- 底部提示：对话流末尾一行小字「由陆耀威自建的个人AI向您回答」。

## 图片展示规范（项目截图 / 实习荣誉配图）

- 缩略图：1px 细线（--hairline）包裹的直角图框，无圆角无阴影；渲染宽度 = 内容宽 × imageWidth%（40/60/80/100），图片 display:block，与标题/要点之间留正常间距。
- 点击缩略图 → 全屏浮层放大：墨黑半透明遮罩（rgba(26,26,26,.85)）+ 居中图片（max-width 92vw / max-height 86vh）+ 右上角「关闭」文字按钮（等宽）；Esc 或点遮罩也可关闭；仅 0.15s 透明度过渡，禁止花哨动效。
- 无图条目：不渲染图框，布局不受影响。

## 管理端结构（/admin）

- 同令牌但偏工具化：左侧栏导航（六类 + 智能体设置 + 备份/恢复），右侧编辑表单。
- 首次进入若 `setupNeeded` → 设置密码；否则登录页。登录态过期 401 → 回登录页。
- 每类内容：列表 + 新增/编辑/删除/排序（上移下移即可）；保存后给出成功反馈。
- 智能体设置表单：Base URL / Model / API Key（占位显示 `sk-***abcd`，留空=不改）/ 追加系统提示词；附「未配置时访客端走离线兜底」的说明文字。
- 备份：一键下载 JSON；恢复：选文件上传。

## 文案基调

- 第一人称、具体、克制；像本人手写，不喊口号。
- 待补充就写「待补充」，不编内容。
